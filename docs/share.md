# CastRoom AI Share Kit

This page contains public-facing copy and demo notes for people who want to share CastRoom AI with testers.

本文档提供可公开使用的项目介绍和 demo 说明，方便把 CastRoom AI 分享给愿意测试的用户。

## Short Description / 短介绍

English:

> CastRoom AI is an early Windows desktop app for running multi-character AI rooms. It focuses on Director-paced scenes, role channels, reviewable memory, and configurable local/external AI.

中文：

> CastRoom AI 是一个早期 Windows 桌面应用，用于运行多角色 AI 房间。重点是 Director 场景推进、角色频道、可审核记忆，以及可配置的本地/外部 AI。

## One-Line Positioning / 一句话定位

English:

> A Windows desktop app for running rooms of AI characters, with Director-paced scenes, scoped memory, and configurable AI.

中文：

> 一个用于运行 AI 角色房间的 Windows 桌面应用，带 Director 场景推进、分作用域记忆和可配置 AI。

## Demo Outline / Demo 说明

A clear 60-90 second demo can show:

1. Launching the latest portable build.
2. Opening a Room with several AI roles.
3. Sending a public message.
4. Director choosing the next speaker and advancing the scene.
5. Showing public, private, and faction channels.
6. Opening Prompt Center to edit Room, Director, and character rules.
7. Opening Memory Graph to review memory candidates and scoped facts.
8. Ending with the GitHub Release download link and GitHub Issues feedback entry.

一个清晰的 60-90 秒 demo 可以展示：

1. 启动最新 portable 版本。
2. 打开包含多个 AI 角色的 Room。
3. 发送一条公开消息。
4. Director 选择下一位发言者并推进场景。
5. 展示公开、私密和阵营频道。
6. 打开 Prompt Center，编辑 Room、Director 和角色规则。
7. 打开 Memory Graph，查看待确认记忆和分作用域事实。
8. 最后展示 GitHub Release 下载入口和 GitHub Issues 反馈入口。

## Screenshot Captions / 截图说明

- Room workspace: Multi-role AI room with shared context, role state, and channel controls.
- Prompt Center: Editable rules for rooms, Director flow, and characters.
- Memory Graph: Reviewable memory candidates, active facts, and relationship inspection.

- Room 工作区：多角色 AI 房间，包含共享上下文、角色状态和频道控制。
- Prompt Center：编辑房间、Director 流程和角色规则。
- Memory Graph：查看待确认记忆、active 事实和关系信息。

## Current Notes / 当前说明

- CastRoom AI is an early release and may change quickly.
- Local model assets may not be included in every release package.
- External AI requires separate provider configuration by the user.
- Feedback is welcome through GitHub Issues.

- CastRoom AI 仍是早期版本，功能和体验可能快速变化。
- 本地模型资源不一定包含在每个发布包中。
- 外部 AI 需要用户自行配置 provider。
- 欢迎通过 GitHub Issues 反馈问题和建议。

# Local Model Assets

Large model files are not stored in the public source repository.

Place downloaded chat models here:

```text
resources/models/chat/<model-id>/
```

Each model directory should include its manifest, license, source notice, and checksum information when available.

If this project publishes an offline asset package through GitHub Releases, extract the model files into the path above.

大型模型文件不进入公开源码仓库。

下载后的聊天模型请放在：

```text
resources/models/chat/<model-id>/
```

每个模型目录应尽量包含 manifest、许可证、来源说明和校验信息。

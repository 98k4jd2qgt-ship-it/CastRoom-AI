# Local Runner Assets

Runner binaries are not stored in the public source repository.

Place downloaded runner files here:

```text
resources/runners/llama.cpp/
resources/runners/whisper.cpp/
```

Runner asset packages should include binary files, license files, source notices, and SHA256 checksums.

If this project publishes an offline asset package through GitHub Releases, extract the runner files into the paths above.

本地 runner 二进制不进入公开源码仓库。

下载后的 runner 文件请放在：

```text
resources/runners/llama.cpp/
resources/runners/whisper.cpp/
```

资源包应包含二进制文件、许可证、来源说明和 SHA256 校验。
